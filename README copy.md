- 필요한 환경 변수는 실제 값이 아닌 이름과 용도만 기록합니다.


## 저장소 구조

- `src/`: 제품 코드
- `tests/`: 자동화 테스트
- `docs/requirements/`: 요구사항과 성공 조건
- `docs/architecture/`: 현재 시스템 구조
- `docs/decisions/`: 중요한 기술 결정 기록
- `docs/rfcs/`: 큰 변경을 위한 사전 제안
- `docs/specs/`: API, 이벤트, 데이터 계약
- `docs/tasks/`: 복잡한 작업의 계획과 이력
- `docs/guides/`: 개발자가 따르는 작업 절차
- `docs/operations/`: 배포, 관측, 장애 대응 절차
