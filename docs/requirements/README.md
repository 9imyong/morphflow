# 요구사항 안내

요구사항은 구현 방법이 아니라 해결할 문제, 필요한 동작, 성공 조건을 설명합니다.

## 작성 규칙

- 요구사항마다 변경되지 않는 식별자를 부여합니다.
- 기능 요구뿐 아니라 성능, 보안, 접근성, 호환성 같은 품질 요구를 포함합니다.
- 검증 가능한 인수 조건을 작성합니다.
- 관련 아키텍처, 결정, 명세, 작업, 테스트를 연결합니다.

새 문서는 [요구사항 템플릿](REQUIREMENTS_TEMPLATE.md)을 복사해 작성합니다.

요구사항에서 바로 구현 방향이 정해지면 Task로 연결합니다. 여러 대안을 검토해야 하는 큰 변경은 RFC로, 중요한 아키텍처 결정이 이미 필요하다고 판단되면 ADR로 연결합니다. 생성·생략 기준은 [문서 운영 정책](../DOCS_GOVERNANCE.md)을 따릅니다.
