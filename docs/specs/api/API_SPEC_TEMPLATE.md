# API 설명: 기능 이름

## 목적

이 API가 해결하는 사용자 문제를 작성합니다.

## 계약 기준

- OpenAPI 위치: `docs/specs/api/openapi.yaml`
- 계약 관리 방식: 계약 우선 / 코드 우선 중 하나를 선택
- 생성 또는 검증 명령: 작성 필요

## 인증과 권한

인증 방식, 필요한 권한, 객체 수준 접근 제어를 작성합니다.

## 주요 시나리오

요청과 응답 예시, 멱등성, 페이지 나누기, 동시성 규칙을 작성합니다.

## 오류 모델

| 상태 코드 | 의미 | 호출자 대응 |
|---|---|---|
| 400 | 잘못된 요청 | 입력 수정 |
| 401 | 인증 필요 | 다시 인증 |
| 403 | 권한 부족 | 권한 확인 |
| 500 | 서버 오류 | 재시도 정책에 따라 처리 |

## 호환성 정책

버전 정책, 폐기 공지 기간, 하위 호환성 기준을 작성합니다.
