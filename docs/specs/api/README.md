# HTTP API 명세 안내

HTTP API가 있다면 `openapi.yaml`을 정확한 계약의 기준으로 사용합니다. 코드에서 자동 생성하는 방식이라면 생성 원본의 위치와 재생성 명령을 여기에 기록하고 생성 파일을 직접 수정하지 않습니다.

사람을 위한 배경과 사용 예시는 [API 설명 템플릿](API_SPEC_TEMPLATE.md)을 사용합니다.

구성 요소가 API로 통신하는 이유와 전체 관계는 [아키텍처](../../architecture/README.md)에 기록하고, 이 문서에는 경로·요청·응답·오류·인증·호환성 계약을 둡니다. 작성 여부는 [기술 명세 안내](../README.md)를 따릅니다.
